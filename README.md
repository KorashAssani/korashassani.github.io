# Korash Assani — personal website

Static HTML/CSS website for GitHub Pages. No build tools are required.

## Preview
Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

## Publish
Review this branch, then merge into the GitHub Pages publishing branch (currently main). Keep the existing repository and URL.

## Update
Edit the relevant HTML page. Shared styling is in styles.css. Replace assets/Korash_Assani_CV.pdf when the updated CV is available. The current PDF is carried over and labeled on the CV page. Google Fonts are optional; system fallbacks are included.

## Image sources
- Cosmic Cliffs: NASA, ESA, CSA, STScI; https://esawebb.org/images/weic2205a/
- Portrait: supplied by Korash Assani. The displayed crop uses CSS; original retained.
- CR schematic: Assani et al. (2026), Figure 4, https://arxiv.org/abs/2607.09407
- Extinction schematic and beta curves: Assani et al. (2025), Figures 6 and 4, https://arxiv.org/abs/2504.02136
- Iron jet channel maps: Assani et al. (2024), Figure 6, https://arxiv.org/abs/2404.18334

Figure exports are cropped from the PDFs with their axes and labels preserved. The extinction schematic includes material adapted in the paper from van Dishoeck et al. (2011).
